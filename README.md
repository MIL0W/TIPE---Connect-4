# Connect Four – Algorithmic Solver

## Project Overview

This project was developed as part of my TIPE. It focuses on solving the game of Connect Four using artificial intelligence and search algorithms.

## Methods

- **Minimax:** explores possible moves to find the best strategy.
- **Alpha-Beta Pruning:** reduces the search space by eliminating unnecessary branches.
- **Heuristic Evaluation:** estimates board positions when the search depth is limited.
